# Breath of Life Connect

Build a modern, animated bilingual (English & Spanish) website and admin CMS for "Breath of Life PDC", a community charity based in Playa del Carmen, Mexico, rebuilding from the attached original page source files (homepage, values, how you can help, volunteer, drop-off points, donations, and contact).

Key requirements:

1. Unified Bilingual Architecture (EN/ES):
   - Seamless language toggle (English / Español) in the navbar that switches content dynamically without separate clone pages.
   - All core content (hero, mission, values, how to help, volunteer info, drop-off locations, tax/donation details) supported in both English and Spanish.

2. Modern, Engaging Animated Design:
   - Clean, welcoming, community-focused visual design with smooth scroll animations, hero section, impact metrics, volunteer call-to-actions, and interactive drop-off location cards with maps/directions.
   - Fully responsive on mobile and desktop.

3. Admin Dashboard & CMS:
   - Admin login to manage content.
   - Dynamic Navigation & Page Manager: allow admins to add, edit, rename, reorder, or toggle visibility of navigation menu items and pages.
   - Content Editor: allow editing section copy, drop-off locations, volunteer needs, and donation methods in both English and Spanish.

4. Page Content from Source Files:
   - Homepage: Mission, caring in action, community programs, impact highlights.
   - Foundational Values & Beliefs (Valores y creencias fundamentales).
   - How You Can Help: Contributions, holiday gift donations, sponsor a family.
   - Volunteer: Volunteer opportunities, sign-up form.
   - Drop-Off Points: Roma Spaghetti, Pueblito Escondido Calle 38, etc., with hours, addresses, and maps links.
   - Donations: USA & Canada tax deductible donation instructions, Mexican donation info, QR codes.
   - Contact Us: Contact form, WhatsApp/phone, email, social links.
